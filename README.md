# Trading Signals Pro

Advanced multi-source trading analysis platform with confluence scoring.

## Features

- **Multi-Timeframe Analysis**: Daily, Weekly, Monthly signals
- **Confluence Scoring**: Combines 10+ data sources for reliable signals
- **Technical Indicators**: RSI, MACD, Stochastic, CCI, Ichimoku, Bollinger Bands, and more
- **Support/Resistance**: Auto-detected key price levels with Pivot Points
- **Risk Analysis**: Volatility, Drawdown, Sharpe Ratio
- **News Sentiment**: Real-time sentiment from 16+ RSS feeds
- **TradingView Integration**: Professional technical analysis
- **350+ Assets**: Stocks, Crypto, Forex

## Data Sources

- Yahoo Finance (price data, analyst ratings)
- TradingView (technical analysis)
- RSS News Feeds (sentiment analysis)
- Fear & Greed Index (crypto)

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
